# 🌾 Agro-Connect

Agro-Connect is a modern agriculture web platform that connects farmers directly with customers and buyers.  
It helps farmers sell their products easily and allows customers to purchase fresh agricultural products directly from producers.

🔗 **Live Website:** https://agro-connect-f25j.vercel.app/

---

## 📌 Project Overview

Agro-Connect aims to eliminate middlemen in agricultural trade by creating a direct farmer-to-customer digital marketplace.

This platform provides:

- Product listing for farmers
- Direct connection between farmers and buyers
- Easy browsing of agricultural products
- User-friendly and responsive design

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/agro-connect.git
cd agro-connect
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the project

```bash
npm run dev
```

Now open:

```
http://localhost:5173
```
